# Database Schema

## Core Tables
- creators - 500K+ profiles
- bookings - Campaign bookings
- claim_requests - Profile claims

## Financial Tables
- transactions - All transactions
- activation_fees - Panel activation
- invoices - VAT invoices
- exchange_rates - Multi-currency
- suspicious_transactions - Fraud alerts

## Compliance Tables
- kyc_verifications - KYC/AML
- user_consents - ToS/Privacy
- audit_logs - Admin audit trail
- disputes - Arbitration

## Infrastructure Tables
- email_queue - Email queue
- slow_queries - Slow query log
