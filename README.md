# SYP Platform - Show Your Profile

**Rule Your Reach** - Global Social Media Creator Marketplace

## Stack
- Next.js 16 (App Router)
- Supabase (PostgreSQL)
- Tailwind CSS v4
- TypeScript

## Quick Start

npm install
npm run dev
